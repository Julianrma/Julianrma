## Proyecto destacado

### SpaMoonBeauty · Gestión y reservas

[![Página principal de SpaMoonBeauty](https://raw.githubusercontent.com/Julianrma/sistema-spaa/main/docs/images/aura-spa-inicio.png)](https://github.com/Julianrma/sistema-spaa)

Aplicación web con portal de clientes y administración para un spa.

- Reservas según sucursal, servicio y disponibilidad del profesional.
- Validación de horarios y prevención de reservas superpuestas.
- Gestión de servicios, profesionales, sucursales y reseñas.
- Autenticación administrativa, estadísticas y pruebas automatizadas.

**Java · Spring Boot · Thymeleaf · PostgreSQL**
